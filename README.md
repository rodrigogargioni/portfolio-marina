# Portfolio · Marina Felix Borges

Landing page de portfolio profissional — Produtora de Eventos, Endomarketing & Live Marketing.

## Stack

- HTML + CSS (Fraunces, Instrument Serif, DM Sans)
- Vanilla JS (IntersectionObserver para reveal animations)
- Deploy estático na Vercel

## Desenvolvimento

Abra `index.html` direto no navegador, ou sirva localmente:

```bash
npx serve .
```

## Deploy

Push no `main` → deploy automático via Vercel.
